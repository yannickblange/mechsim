How to use:
- One step per session: type `/clear`, then paste exactly one prompt.
- Wait for the commit, then paste the next step.
- At a **Merge point**, you (the human) merge the branch into main in your main folder:
  `cd ~/Software/Mechanics_Simulator && git merge <branch>`.
  The first step of the next ticket creates its branch from the updated main.
- If a step was half-done in an earlier session, just paste it again: the agent checks
  existing code instead of rewriting it.
- Steps marked **Human check** need you to open the browser; the agent cannot do that.
