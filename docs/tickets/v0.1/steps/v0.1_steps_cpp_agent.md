Task: solveAccelerations(sys, acc, lambda). acc.resize(n), lambda.resize(m).
- m == 0: acc[i] = f[i]/mass[i]; return 0.
- Otherwise (Schur complement, M is diagonal):
  A (m x m): A[r*m+s] = sum over k of G[r*n+k] * G[s*n+k] / mass[k]
  rhs (m):   rhs[r] = gamma[r] - sum over k of G[r*n+k] * f[k] / mass[k]
  if la_solve(A.data(), m, rhs.data()) != LA_OK return -1;  lambda = rhs
  g = G^T lambda (use la_matvec_t);  acc[k] = (f[k] + g[k]) / mass[k]
- Use std::vector buffers. Return 0.
